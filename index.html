PromptToPlay · 在线体验版 · 源码 · 完整版（登录 / 积分 / 游戏大厅 / 支付）

完整版是 Node.js + Express + SQLite，可本地一条命令启动；本页是纯静态版，可直接部署到 GitHub Pages。

三种玩法

  1. 示例体验：不填 Key，点示例游戏直接玩——这些是 DeepSeek 预先生成的成品，用来验证「生成出来的东西真的能玩」。
  2. 实时生成：填入自己的 DeepSeek API Key（在 这里 申请），输入一句话，浏览器直接调用 DeepSeek 生成新游戏，可下载成 HTML 文件。
  3. 完整版：npm install && npm start 后访问 http://localhost:3000，有账号、积分、游戏大厅和支付，服务端持有 Key，前端无需填。

成本参考：一次生成约 1.6 万 token 上限，按 DeepSeek 现价约 ¥0.1 以内。
